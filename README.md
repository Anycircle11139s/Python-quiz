# Python-quiz
This is a prject i quite enjoyed making, and it is a fun, interactive quiz designed to test users knowlege of both hardware and software terms, allowing them to also creat their own mini quiz at the end!
Can be played by on's self or in pairs
have fun :D

The thing works by printing questions, getting inputs, stripping the inputs of formatting and then checking if the answers match. This is similar to when the person is allowed to make their own question. This is done by letting them create the variable for the answer and comparing if the first variable = the second variable. 

I made this because I wanted to get into python and I thought this would be a simple introduction project to begin my python journay. I wanted to learn python because I made a bet with a random person on slack that I would learn software if they learnt hardware.
